# 在 ChatGPT 中使用

ChatGPT 的 **Agent 模式**自带一个云端浏览器，可以打开网页并填写表单，但**不能直接读写你电脑上的文件**。

1. 新建一个项目（Project），把 `AGENTS.md` 的内容粘贴到项目指令里。
2. 把 `my-data/` 里的 `profile.json`、`answers.md`、`rules.md`、`aliases.json` 作为项目文件上传。
3. 开启 Agent 模式，发送：「帮我填这个网申：<链接>」。需要登录时，在 Agent 浏览器里自己登录。
4. 结束时让它输出「需要写回资料库的更新」和「投递记录新行」，手动粘贴回本地文件。

> 各家产品功能更新很快，以官方最新说明为准。
