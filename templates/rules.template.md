# 我的自定义规则

## 投递与提交
- 用户让你填的网申，填完即视为已投递，自动记入投递记录（默认开启，删掉此行即关闭）
- 不要替我点最终「提交」按钮（默认开启；如要允许自动提交，改成：允许自动提交，提交前先截图给我看）

## 常见选项
- 是否有本公司亲属 → 一律「没有」
- 是否在本公司实习过 → 一律「否」
- 是否服从调剂 → 一律「是」
- 健康状况 → 选「健康」，没有就选最好的一档
- 了解渠道 → 优先「官网」，没有选「其他」
- 选填附件（推荐表、证书复印件等）→ 一律不填
